# Voice lane harness

These scripts produced the device results in `docs/evidence/voice/` and `docs/evidence/lane0/`. They are committed so that the evidence can be
regenerated by anyone, against any deployed origin (production, dev, a preview, or a local build). They contain no hostnames, serials, tokens or
credentials: everything site- or device-specific is an argument or an environment variable.

Nothing here touches a device unless you point it at one yourself (a CDP port or a WebDriver URL that you provide).

## Common rules

- `ORIGIN` (environment variable) is the site to test, for example `ORIGIN=https://dev.privatelocal.chat` or `ORIGIN=http://127.0.0.1:18171`
  for `node scripts/serve.mjs`. There is no default: a missing `ORIGIN` stops the script.
- `--decision-only` asks the real voice controller what it would do on this device and stops. It never calls `createVoiceEngine`, never installs,
  speaks or removes anything, and no model file is requested. (The controller's own storage write test can briefly write and delete a scratch
  file in the origin's private storage, as it does in normal use.) Use it on any device you do not want to put a model on.
- Without `--decision-only` the run installs the voice the controller picks from the hosted files (27.6 MB Kitten or 96.5 MB Kokoro), speaks one
  sentence, measures it, then unloads and removes it and reports the storage estimate before and after. Do that only on a device you may use for
  it (enough free space, battery at 15 % or more, the owner's permission).
- Install `npm ci` once at the repository root: Playwright and `ws` are resolved from there.
- The output is one JSON file per run (`--out`), plus one summary line on the console.

## Files

| File | What it is | Needs |
|---|---|---|
| `voice-lane.js` | The in-page function body. Step 1: the controller's decision (offer or not, candidate, reason, stage, download bytes). Step 2 (skipped by `--decision-only`): install, speak, real-time factor, first-audio time, verdict of `voiceIsFastEnough`, unload, remove, storage before/installed/after. Never run by hand: a driver evaluates it. | a driver below |
| `lane-pw.mjs` | Playwright driver. Launches chromium, webkit or firefox, or attaches to a Chromium that already listens for CDP (`--cdp-port`). | `playwright` (npm), `ORIGIN` |
| `lane-wd.mjs` | W3C WebDriver driver, for browsers Playwright cannot drive (stock Firefox through geckodriver, Safari through safaridriver). | a WebDriver server you start, `ORIGIN` |
| `cdp-eval.mjs` | Evaluates one script in one already open page, matched by URL prefix, over raw CDP. Used for phones (Chrome over `adb forward`) and for browsers behind an SSH tunnel. | a CDP port (local, `adb forward`, or an SSH `-L` tunnel), the `ws` package |
| `lane0-collect.js` | In-page function body for the read-only Lane 0 inventory: user agent, cores, `deviceMemory`, cross-origin isolation, SIMD, storage estimate, OPFS, WebGPU adapter and limits, speech voices (names and languages), a timed JS loop. | a driver |
| `lane0-pw.mjs` | Playwright driver for `lane0-collect.js`, with `--flag=<chromium argument>` for runs with GPU flags, and `--cdp-port`. | `playwright`, `ORIGIN` |
| `dev-actions.mjs` | Lane 5: starts a local DEV build (via `tests/e2e/harness.mjs`) and drives the `voice-state`, `voice-decide` and `voice-cycle` actions of the dev command channel. | `playwright`, network for `voice-cycle` |

## Exact commands

Desktop, any Playwright browser, decision only (nothing installed):

    ORIGIN=https://dev.privatelocal.chat node ops/voice/lane/lane-pw.mjs --browser chromium --out lane-chromium.json --decision-only
    ORIGIN=https://dev.privatelocal.chat node ops/voice/lane/lane-pw.mjs --browser webkit   --out lane-webkit.json   --decision-only

Desktop, full cycle (installs, speaks, removes):

    ORIGIN=https://dev.privatelocal.chat node ops/voice/lane/lane-pw.mjs --browser chromium --out lane-chromium.json

A Chromium on another machine, over an SSH tunnel (start Chromium there with `--remote-debugging-port=9222`, then):

    ssh -N -L 19335:127.0.0.1:9222 <host> &
    ORIGIN=https://dev.privatelocal.chat node ops/voice/lane/lane-pw.mjs --cdp-port 19335 --out lane-remote.json --decision-only

Firefox through WebDriver:

    geckodriver --port 4444 &
    ORIGIN=https://dev.privatelocal.chat node ops/voice/lane/lane-wd.mjs --driver http://127.0.0.1:4444 --out lane-firefox.json --decision-only
    # a driver on another machine: ssh -N -L 4444:127.0.0.1:4444 <host>, then the same command

An Android phone with Chrome (USB debugging on, a tab already open on the origin):

    adb forward tcp:9222 localabstract:chrome_devtools_remote
    node ops/voice/lane/cdp-eval.mjs 9222 https://dev.privatelocal.chat/ ops/voice/lane/lane0-collect.js lane0-phone.json
    node ops/voice/lane/cdp-eval.mjs 9222 https://dev.privatelocal.chat/ ops/voice/lane/voice-lane.js lane-phone.json --decision-only

iPhone or iPad (Safari): there is no Playwright or CDP path to a phone. Open the page in Safari, paste the body of `lane0-collect.js` or
`voice-lane.js` (after setting `window.__voiceDecisionOnly = true` for decision only) into the Web Inspector console of a Mac that has the
device attached, and save the returned object. The committed negative test for iOS is `tests/e2e/voice-ios.e2e.mjs`, which uses WebKit with the
iPhone profile and a network log.

Lane 0 inventory (read only), including a GPU-flags run:

    ORIGIN=https://privatelocal.chat node ops/voice/lane/lane0-pw.mjs --browser chromium --out lane0-default.json
    ORIGIN=https://privatelocal.chat node ops/voice/lane/lane0-pw.mjs --browser chromium --out lane0-flags.json --flag=--enable-unsafe-webgpu

Lane 5 (local dev build, dev command channel):

    node ops/voice/lane/dev-actions.mjs voice-state voice-decide

## Reading a result

`decision.offer` / `decision.candidate` / `decision.reason` are what the shipped controller would do. `speak.realTimeFactor` is audio seconds per
synthesis second (above 1 keeps up with playback). `verdict.fastEnough` and `verdict.startDelayMs` apply the shipped limits. The storage figures
are `navigator.storage.estimate()`, which includes the app shell cache and is not exact on every browser (see the gap analysis, row 48), so
compare them with the private-storage byte count of `tests/e2e/voice-engine.e2e.mjs`, not as a pass/fail on their own.
