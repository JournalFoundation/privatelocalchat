      Private & Local — About this demo
      
        
      
      
      
      
        
      The app runs in your browser. Your chats are stored locally. On-device models generate locally; choosing an API provider sends conversation context to that provider.
      

        
      How to run it anywhere
      
        
        
          
      • Desktop: Install this app from your browser, or bookmark it.
        • 
          
      • iPhone (Safari): Share → Add to Home Screen, or Share → Save to Files, then open it.
        • 
        
      

        
      What’s stored locally
      
        
        
          
      • localStorage: chat threads and messages.
        • 
          
      • sessionStorage: settings (endpoint, token, model, theme) for the current session.
        • 
        
      
        
      Model downloads require a connection. After installation, on-device chat can work offline. API mode uses your selected provider.
