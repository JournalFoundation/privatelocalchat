# PrivateLocal.Chat brand assets

From the PrivateLocal.Chat Brand Packet v1.0 (2026-10-30). The geometric mark and layout were created for the packet; wordmark lettering is outlined from DejaVu Sans (see WORDMARK_FONT_LICENSE.txt). No font files are shipped; the app uses the system sans-serif stack.

| File | Use |
|---|---|
| `wordmark-light.svg` / `wordmark-dark.svg` | Header wordmark on light / dark surfaces (min width 156 CSS px) |
| `mark-light.svg` / `mark-dark.svg` | The mark alone (min 20 CSS px) |
| `favicon.svg`, `favicon.ico`, `favicon-64.png` | Browser tab |
| `apple-touch-icon-180.png` | iOS home screen |
| `app-icon-192.png`, `app-icon-512.png`, `app-icon-maskable-512.png` | Web app manifest (maskable only for the maskable file) |
| `social-card-1200x630.png` | Link previews |
| `design-tokens.css` | Colour, spacing, radius and motion tokens (`--plc-*`) |

Keep clear space around the wordmark equal to half the mark height. Do not add faces, padlocks, shields, gradients or glow to the mark.
